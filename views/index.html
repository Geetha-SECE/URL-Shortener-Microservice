URL Shortener Microservice

Submit a URL and receive a numeric short URL that redirects to it.

Example usage

  • Submit a URL: 
    POST /api/shorturl
Content-Type: application/x-www-form-urlencoded

url=https://www.freecodecamp.org
  • Response: 
    { "original_url": "https://www.freecodecamp.org", "short_url": 1 }
  • Visit the short URL: GET /api/shorturl/1 → redirects to https://www.freecodecamp.org
  • Invalid or unreachable URLs return: 
    { "error": "invalid url" }
